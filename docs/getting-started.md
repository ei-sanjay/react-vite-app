# Getting started

Welcome to **react-vite-vitest-cypress**, a React starter generated by `create-react-starter-kit`.

This guide walks you from first install to extending the app with confidence.

## Prerequisites

- **Node.js 18+** (20 LTS recommended)
- **pnpm** installed globally or via Corepack
- A modern browser for the demo UI

## Install & run

```bash
git init
pnpm install
pnpm dev
```

Install **must** run after `git init`. The `prepare` script (`husky`) only creates git hooks when a `.git` directory already exists.

Dev server URL (default): **http://localhost:5173**

Useful scripts:

| Script                | Purpose                                |
| --------------------- | -------------------------------------- |
| `dev`                 | Local development server               |
| `build`               | Production bundle                      |
| `preview`             | Serve the production build locally     |
| `test` / `test:watch` | Unit tests                             |
| `test:e2e`            | End-to-end tests                       |
| `test:e2e:install`    | Download the Cypress app binary (once) |
| `storybook`           | Component explorer                     |
| `lint` / `format`     | Code quality                           |

## Git hooks

| Hook         | What it runs                      |
| ------------ | --------------------------------- |
| `pre-commit` | `lint-staged`                     |
| `commit-msg` | commitlint (Conventional Commits) |
| `pre-push`   | `pnpm run test`                   |

After `git init`, run `pnpm install` so Husky can install those hooks.

## Environment variables

1. Copy `.env.example` → `.env`
2. Fill values for your environment
3. Restart `dev` after changes

Only client-safe variables (typically `VITE_*`) are exposed to the browser. Never put private API keys in front-end env vars.

| Variable            | Purpose                                                   |
| ------------------- | --------------------------------------------------------- |
| `VITE_API_BASE_URL` | REST API base URL (defaults to JSONPlaceholder for demos) |
| `VITE_SENTRY_DSN`   | Sentry DSN                                                |

## What to explore first

1. **`/`** — stack badges and orientation
2. **`/counter`** — client state (Redux Toolkit)
3. **`/posts`** — server state (RTK Query)
4. **`/feedback`** — forms + validation (None / None)
5. **`docs/selected-stack.md`** — why each library was chosen
6. **`docs/examples/`** — deep usage guides with copy-paste patterns

## Extending the app (recommended flow)

1. Create a feature folder: `src/features/<domain>/`
2. Add UI, hooks, and domain types next to that feature
3. Register a route in `src/App.tsx`
4. Put shared primitives in `src/components/`
5. Add RTK Query endpoints in `src/store/` (or a feature-local `*Api` slice)
6. Put path constants in `src/config/routes.ts` and `src/config/api-routes.ts`
7. Import with `@/` — e.g. `import { ROUTES } from '@/config/routes'`

## Testing

- Unit: `pnpm test`
- E2E: `pnpm test:e2e:install` (once), then `pnpm test:e2e`
- Storybook: `pnpm storybook`

See `docs/best-practices.md` and `docs/examples/testing.md` for strategy and CI notes.
